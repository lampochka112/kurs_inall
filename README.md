# ИНАЛЛ ПРОШУ ВАС ПОСТАВЬТЕ МНЕ ЗАЧЕТ 5

**Полный курс HTML · CSS · JavaScript — от новичка до уверенного джуна**

## 💡 О проекте

**WebCourse Pro** — это интерактивный сайт-читалка с полным курсом по веб-разработке. Один HTML-файл, который работает прямо в браузере без сборки и зависимостей.

Курс построен по принципу **двух уровней**:
- 🟢 **Базовый** — для тех, кто начинает с нуля
- 🔵 **Продвинутый** — для тех, кто уже знает основы и хочет углубиться

### ✨ Возможности

| Возможность | Описание |
|-------------|----------|
| 📚 **13 модулей** | HTML (3), CSS (4), JavaScript (5), Проекты (1) |
| 🎚 **Два уровня** | Переключение между базовым и продвинутым материалом |
| 🔍 **Поиск** | `Ctrl/Cmd + K` — мгновенный поиск по всему курсу |
| 📊 **Прогресс** | Отметка «пройдено», сохранение в `localStorage` |
| 🌗 **Тёмная / светлая тема** | Запоминается между сессиями |
| 📱 **Адаптив** | Работает на телефоне, планшете, десктопе |
| 📖 **Шпаргалки** | Краткий справочник по HTML, CSS, JS |
